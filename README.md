# Obsidian CSV Support

A plugin for [Obsidian](https://obsidian.md) that provides seamless CSV file support right in the editor.

## Features

- **Only Works in Editing Mode**: This plugin is designed to work only in editing mode, ensuring a clean and focused experience.
- **Open CSV Files**: View CSV files directly in Obsidian
- **Edit CSV Files**: Make changes to your data without leaving Obsidian
- **Save CSV Files**: Changes are saved automatically
- **Native Editor Experience**: Works with Obsidian's editing capabilities
- **Color Highlighting**: Different colors for each column to improve readability

Not Yet Ready but you can build it yourself and copying the [`manifest.json`,`styles.css`,`main.js`] files to your vault's plugins folder usually `$USERPATH/.obsidian/plugins/obsidian-csv-support`.
